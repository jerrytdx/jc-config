# 即创自动化 授权与版本

当前版本：**1.3.3**，加入本机记住密码，界面统一为“即创自动化”。发布时总开关保持 **off**。

## 登录与记住密码

登录页使用“输入密码”“登录密码”“请输入密码”。默认勾选“记住密码”：
成功登录后通过 Windows DPAPI 加密保存在当前 Windows 用户的应用数据目录。
下次打开自动填入，仍需点击“登录”联网验证。取消勾选立即清除本机保存的密码。
其他电脑或 Windows 用户无法直接使用该加密记录。
服务器确认旧密码已失效时清除匹配的本机旧密码；网络故障或服务暂停不清除记录。
密码不内置在 EXE 中，不写入普通设置或浏览器存储。

## 在哪里修改登录密码

**在服务器修改，不在 GitHub 修改。** 服务器私有文件：

`/private/jc-license-v2/config.json`

- 修改 `card_key` 为新密码，保留其他字段；字段名为兼容旧版沿用。
- 修改 `status` 为 `on` 开启、`off` 关闭，保留密码字段。
- `min_version` 保持 `1.3.2`，支持 1.3.2 和 1.3.3。
- 不要用旧版只有 status/min_version 的配置模板覆盖整个文件。

管理员工具 `python manage_switch.py set-card` 交互询问新密码和 FTP 密码，
只更新密码，保持开关状态。`on`、`off`、`show` 分别用于开启、关闭和查看状态。
工具不回显登录密码或 FTP 密码。

服务器更换密码无需重新发包；运行中的客户端在下次复查时拒绝旧密码并关闭工作台。
每 30 秒复查，新任务前刷新超过 5 秒的授权。正确密码也不能绕过 off 开关。
已经提交到即创云端的任务不因此取消。

授权接口：`https://www.xrt666.top/jc-license-v2/authorize.php`。
客户端只通过 HTTPS 校验密码与签名，不读取 GitHub 中的密码。
